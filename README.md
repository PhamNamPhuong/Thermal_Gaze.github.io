## 1. Program Overview

Eye Heatmap is an interactive generative artwork that 
explores climate change through the human eye.

By applying a procedurally generated heatmap to a 3D 
eye model, the project aims to bring climate change 
closer to the human experience, rather than presenting 
it as a distant environmental issue.

The project combines creative coding, 3D modelling, 
custom shaders, sound design, and user interaction 
to communicate the urgency of climate action.


## 2. Usage Notes

The project is hosted on GitHub Pages and can be 
accessed directly through a web browser.

**Live Demo:** [View Project](YOUR_GITHUB_PAGES_URL)

- Open the project using the link above.
- Move your mouse around the screen to interact with the eye.
- Observe the generated heatmap patterns and colour variations.
- Refresh the webpage to generate a new heatmap pattern.
- Hover over the underlined "More" text to learn more about the project.
- Enable sound for the full audiovisual experience.
- Click anywhere on the webpage if the audio does not start automatically.

For the best experience, use a desktop or laptop 
computer with a WebGL-compatible browser, preferably 
Google Chrome.

## 3. Installation Instructions

### Online Access

No installation or additional plug-ins are required.
The project can be accessed directly through GitHub Pages.

### Local Installation (Optional)

If you wish to run or modify the source code locally:

1. Visit the project's GitHub repository.
2. Download the repository as a ZIP file or clone it using Git.
3. Extract the downloaded folder.
4. Open the project folder in Visual Studio Code.
5. Install the Live Server extension.
6. Right-click `index.html` and select "Open with Live Server".

### System Requirements

- A modern web browser with WebGL support.
- Internet connection for online access and external libraries.
- Hardware acceleration enabled for optimal performance.

All project files and asset folders should remain in 
their original structure to ensure that the 3D models, 
shaders, and audio files load correctly.

### Requirements

- Visual Studio Code (VS Code)
- A modern web browser, preferably Google Chrome
- Live Server extension for VS Code
